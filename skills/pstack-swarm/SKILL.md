# Delegate by responsibility

Name the question or done predicate, required coverage and deliverable. Choose
coverage slices, independent alternatives, or both. A coverage task completes
only when required slices have evidence; first success cannot close it.
For competing attempts, state the comparison/selection criterion before launch.

Choose the smallest useful worker set. Distinguish total responsibilities from
simultaneous concurrency. Respect available slots, time budget, app isolation
and the parent review capacity. A simple task can stay in the parent. No fixed
agent count, required cloud placement or automatic multi-model panel.

Each standalone brief includes original intent and later corrections, its
responsibility, relevant file pointers, permitted actions, completion evidence
and return shape. For measurements or revision comparisons, specify the exact
versions and method. Give writers disjoint files, isolated outputs/worktrees,
or a single shared-state owner. Reuse the existing harness's worker types where
they fit. Read-only source work can use `pstack-investigator`; otherwise use the
actual supported agent tools with the appropriate permissions and contract.

Let workers choose their searches and implementation steps. Inherit the model
unless a supported role mapping or explicit model comparison was chosen. Never
invent tool arguments, models or remote environments. If delegation is absent,
work sequentially through the selected responsibilities and say so.

Read the findings and the necessary artifacts. Worker labels may be PASS,
ISSUES or BLOCKED, but their evidence determines the conclusion. Check source
and meaningful receipts; agreement does not replace observation. Resolve
contradictions before synthesis. A dropped worker or blocked environment is a
gap, not a clean result. Retry only when a bounded retry can add missing evidence;
do not create an endless respawn loop.

Return one concise report: what the combined work establishes, what changed if
edits were authorized, relevant evidence, disagreements and remaining coverage
gaps. The parent owns the final answer and delivered changes.

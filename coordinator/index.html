Exercise the methods

The walkthrough checks actual behavior against documentation. The coverage trial asks two independent investigators to cover different questions and requires the parent to check both. The impact trial assesses a hypothetical change without applying it.

Your Hermes interfaces

Use the home-network links on devices connected to the same network. Localhost means the device you are using. Links away from home require your private VPN.

Where are the agents?

The coordinator is Hermes itself: the parent agent chooses work, delegates it and checks the results. Pstack supplies methods for choosing and reviewing that work.

Worker coverage shows actual subagent start/stop receipts, parent relationships and durable delegations. Session records show history. The task board shows the existing Hermes Kanban. Empty sections mean no matching evidence, not a hidden fleet.

The native dashboard provides chat, sessions, skills, models and configuration. Its embedded chat can show workers from its own live session; older CLI workers are not automatically live there.

Agents & delegation

Hermes is the parent coordinator. A subagent is a worker it asks to investigate part of a question. The parent checks the result. Completed workers below are history, not agents running now.

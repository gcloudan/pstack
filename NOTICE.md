# Origin and scope

Adapted from Lauren Tan's MIT-licensed pstack automate-me workflow in
[cursor/plugins](https://github.com/cursor/plugins/tree/23e4138daa01c42d4969f7a5465f82704e64f798/pstack),
snapshot version 0.15.6. The original copyright and permission notice are in
LICENSE. This kit contains adapted instructions and a previously trialled
repository-onboarding workflow; it is not the complete pstack plugin.

The starter work-mode reflects selected explicit preferences from the current
investigation conversation, with the limited evidence documented in
docs/preference-seed.md. No full-history mining has been performed. The kit
does not add models, subagent tools, transcript access or project permissions.
